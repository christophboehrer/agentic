# Exploration and optimization

Set an outcome appropriate to the work. The goal may be to investigate options, compare approaches, or try to improve the current result and report what happened. A best-effort goal can leave the result or numerical improvement open.

Before pursuing optimization, agree with the user on the target, approach, and stopping conditions. The user shapes the method unless they explicitly delegate it. Record the agreement and any delegation. Carry out routine steps under that agreement. Discuss material changes with the user when they fall outside the agreed delegation.

Use `sima-record-work` for remote checkpoints and meaningful attempts. At the agreed stopping point, pause and report the attempts and findings, including a result with zero improvement. The user decides whether to continue, conclude, or move to other work. Follow that decision before closing the task or its issue.
